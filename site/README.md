# PHPlumb website

The promotional page published at <https://lussoluca.github.io/phplumb/>. It is a static [Next.js](https://nextjs.org) export built on the [Tailwind Plus](https://tailwindcss.com/plus) Salient template.

## Development

Install the dependencies once, then start the development server:

```sh
npm install
npm run dev
```

The site lives under the `/phplumb` base path, so open <http://localhost:3000/phplumb>.

`npm run build` writes the static site to `out/`. `npm run lint` checks the code.

## Publishing

The `Pages` workflow builds the site and publishes it to GitHub Pages on every push to `main` that changes this folder.
